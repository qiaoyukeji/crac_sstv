使用说明

本工具在浏览器内本地完成全部音频合成与解码，不依赖任何网络。 发射：把图片编码为 SSTV 音频（FM 单音，1500–2300 Hz）用于播放或导出； 接收：从音频文件或麦克风还原图像。

支持的制式

Martin M1 / M2、Scottie S1 / S2、Robot 36、PD90。前四种为 RGB 直传；后两种为 YUV（色度半分辨率）。

频率映射

黑 1500 Hz，白 2300 Hz，同步 1200 Hz，VIS 引导 1900 Hz。与 pySSTV 0.5.9 兼容。

离线运行

直接双击 index.html 即可使用文件发射/接收与导出。全部为本地计算。

麦克风权限

浏览器要求安全上下文。getUserMedia 在 file:// 常被拦截，需用本地服务器打开（见下方提示）。

提示：若需使用麦克风（实时接收），请在本目录运行 python -m http.server 8000 然后访问 http://localhost:8000。文件导入、播放、WAV/PNG 导出在纯本地（file://）下均可正常工作。 长时长制式（如 Martin M1 ≈ 115 s）解码需数秒，请耐心等待进度提示。
