使用说明

本工具在浏览器内本地完成全部音频合成与解码，不依赖任何网络。 发射：把图片编码为 SSTV 音频（FM 单音，1500–2300 Hz）用于播放或导出； 接收：从音频文件或麦克风还原图像。

支持的制式

Martin M1 / M2、Scottie S1 / S2、Robot 36、PD90。前四种为 RGB 直传；后两种为 YUV（色度半分辨率）。

频率映射

黑 1500 Hz，白 2300 Hz，同步 1200 Hz，VIS 引导 1900 Hz。与 pySSTV 0.5.9 兼容。

离线运行

直接双击 index.html 即可使用文件发射/接收与导出。全部为本地计算。

画面适配

制式画布尺寸固定（多为 320×256，即 5:4），与照片比例常不一致。适应完整保留、多出部分补黑边；填充填满画布但裁掉溢出；拉伸铺满但会变形。预览框显示的即真正待发送的位图。

发送进度

发送时图片上会覆盖一层遮罩：已发送部分保持清晰，未发送部分压暗，中间一条扫描线推移并显示百分比与计时——与你对端正在收到的画面同步。

实时逐行成像

用麦克风接收时，画面会随着信号到达自上而下逐行生长，而不是等录音结束才一次性出图——和你对面电台正在发送的进度同步。顶部徽标显示已收到的行数与百分比，扫描线标出正在写入的那一行。整幅收满后会自动停止录音，并用批量算法精确重解一遍。

麦克风权限

浏览器只允许安全上下文使用麦克风：http://localhost 可以，http://局域网IP 与 file:// 不行（接口会被直接隐藏）。

本机使用：在项目根目录运行 python web/serve.py，然后访问 https://localhost:8443（或 http://localhost:8000），麦克风可用。
手机 / 平板使用：同样运行 python web/serve.py，先按 HTTPS_MIC_GUIDE.md 在设备上安装根证书， 再用 https://<本机IP>:8443 打开，麦克风才可用。
纯 file:// 双击打开：文件导入、播放、WAV/PNG 导出均正常，仅麦克风不可用。
麦克风接收：画面随信号逐行生长；长制式（Martin M1 ≈ 115 s）本来就要播这么久， 边收边看即可。整幅收满会自动停止；若信号有中断，也可随时手动停止，随后再跑一次批量精确重解。
文件解码：仍是一次性解调，长制式需数秒，请耐心等待进度提示。

本应用在手机本地完成全部音频合成与解码，不申请联网权限。 发射：把照片编码为 SSTV 音频（FM 单音，1500–2300 Hz），用手机对着电台送话器播放； 接收：用麦克风对准电台喇叭，把信号还原成图片。

支持的制式

Martin M1 / M2、Scottie S1 / S2、Robot 36、PD90。前四种为 RGB 直传；后两种为 YUV（色度半分辨率）。

发射（图片 → 音频）

从相册选一张照片 → 点「生成音频」→ 点「发送」，把手机扬声器对准电台送话器。发送时图片上会有一条扫描线自上而下推移，标出对端此刻正在收到的位置。

接收（音频 → 图片）

切到「麦克风」，把手机放在离电台喇叭 10–30 cm 处，点「开始录音」。画面会随着信号到达自上而下逐行生长，整幅收满后自动停止，随后再精确重解一遍。

接收完成自动停止

解码器收满整幅行数即自动结束录音，不必再盯着屏幕手点停止。若信号中途有强噪声导致始终收不满，可随时手动点「停止录音」，此时保留已收到的部分。

导出与保存位置

导出的图片保存在系统相册的 SSTV 相簿里；导出的音频（WAV）保存在文件 → 下载 → SSTV 目录。用系统相册或文件管理器即可打开。

麦克风权限

接收需要麦克风权限，首次录音时系统会弹出授权提示。若曾误点拒绝，请到「设置 → 应用 → SSTV Studio → 权限」中重新允许「麦克风」，再回到应用重试。

完全离线

本应用不申请联网权限，也没有任何网络请求：所有音频合成、解调与图像生成都在手机本地完成，任何数据都不会离开设备。

收不到完整画面？先确认环境噪声够小、手机没有离喇叭太远；音量过大会削波，反而更难解。 也可以在「解码模式」里手动指定制式后重试，或切到「文件」导入对讲机的录音来解码。
长制式要有耐心：Martin M1 整幅约 115 s，这本来就是它的传输时长，边收边看即可。
