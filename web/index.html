使用说明

本工具在浏览器内本地完成全部音频合成与解码，不依赖任何网络。 发射：把图片编码为 SSTV 音频（FM 单音，1500–2300 Hz）用于播放或导出； 接收：从音频文件或麦克风还原图像。

支持的制式

Martin M1 / M2、Scottie S1 / S2、Robot 36、PD90。前四种为 RGB 直传；后两种为 YUV（色度半分辨率）。

频率映射

黑 1500 Hz，白 2300 Hz，同步 1200 Hz，VIS 引导 1900 Hz。与 pySSTV 0.5.9 兼容。

离线运行

直接双击 index.html 即可使用文件发射/接收与导出。全部为本地计算。

画面适配

制式画布尺寸固定（多为 320×256，即 5:4），与照片比例常不一致。适应完整保留、多出部分补黑边；填充填满画布但裁掉溢出；拉伸铺满但会变形。预览框显示的即真正待发送的位图。

发送进度

发送时图片上会覆盖一层遮罩：已发送部分保持清晰，未发送部分压暗，中间一条扫描线推移并显示百分比与计时——与你对端正在收到的画面同步。

实时逐行成像

用麦克风接收时，画面会随着信号到达自上而下逐行生长，而不是等录音结束才一次性出图——和你对面电台正在发送的进度同步。顶部徽标显示已收到的行数与百分比，扫描线标出正在写入的那一行。停止录音后会自动用批量算法精确重解一遍，保证最终结果与参考实现完全一致。

麦克风权限

浏览器只允许安全上下文使用麦克风：http://localhost 可以，http://局域网IP 与 file:// 不行（接口会被直接隐藏）。

本机使用：在项目根目录运行 python web/serve.py，然后访问 https://localhost:8443（或 http://localhost:8000），麦克风可用。
手机 / 平板使用：同样运行 python web/serve.py，先按 HTTPS_MIC_GUIDE.md 在设备上安装根证书， 再用 https://<本机IP>:8443 打开，麦克风才可用。
纯 file:// 双击打开：文件导入、播放、WAV/PNG 导出均正常，仅麦克风不可用。
麦克风接收：画面随信号逐行生长；长制式（Martin M1 ≈ 115 s）本来就要播这么久， 边收边看即可。停止录音后还会再跑一次批量精确重解（数秒），用于校验与导出。
文件解码：仍是一次性解调，长制式需数秒，请耐心等待进度提示。
